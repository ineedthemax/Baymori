# Baymori website (design refinement)

Next.js + React + TypeScript + Tailwind. Includes the original animated Dot Field hero, services, responsive tools diagram, hosting/migration page, FAQ, and live Jotform inquiry embeds.

## Local use

```bash
npm install
npm run dev
```

Visit http://localhost:3000 and http://localhost:3000/transfer.

## Live forms
- General inquiries: https://form.jotform.com/263155617068057
- Hosting migration: https://form.jotform.com/263155490983062

Before launch: test Jotform delivery and notifications, replace any required privacy/legal copy, confirm domain and customer support contact, and run desktop/mobile QA plus a production build. The site intentionally makes no claim of an official Cloudflare partnership.
